## Project shape

Single Next.js 16.4.6 App Router app (not a monorepo). React 19.3, TypeScript strict, Tailwind CSS 4, shadcn/ui.

- Source lives in `src/`; route entrypoints are `src/app/layout.tsx` and `src/app/page.tsx`. The `@/*` path alias maps to `src/*`.
- `src/components/ui/*` was generated by the shadcn CLI (`components.json`, style `base-nova`). Add/refresh components with `npx shadcn add <component>` rather than hand-writing ones that already exist.
- `cn` is re-exported from the `cn` npm package in `src/lib/utils.ts` — do not "fix" it back to the usual `clsx` + `tailwind-merge` implementation.
- Tailwind 4 is CSS-first: there is no `tailwind.config`. Tokens live in `src/app/globals.css`, and Tailwind runs via the `@tailwindcss/turbopack` loader rule in `next.config.ts` (not PostCSS).
- `README.md` is untouched create-next-app boilerplate and stale (it points at `app/page.tsx`; routes are actually under `src/app/`). Trust the config and code, not the README.

## Commands

Verify in this order: `npm run lint` → `npx tsc --noEmit` → `npm run build`.

- `npm run dev` — dev server; Turbopack is the default bundler.
- `npm run lint` — plain `eslint` with the flat config in `eslint.config.mjs`. There is no `next lint`, no Prettier, no formatter.
- No `typecheck` script — use `npx tsc --noEmit`. No test script and no test suite at all; don't hunt for one.
- No CI and no pre-commit hooks; lint/typecheck/build are entirely on you.
- Known state: `npm run lint` exits 1 with 2 pre-existing `react-hooks/set-state-in-effect` errors in shadcn files (`src/components/ui/carousel.tsx`, `src/hooks/use-mobile.ts`). Not your fault unless you touched those files.
- `npx tsc --noEmit` and `npm run build` both pass on a clean tree.
